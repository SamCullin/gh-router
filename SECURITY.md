# Security Policy

## Supported versions

Only the latest published release receives security fixes. Upgrade to the latest version before investigating a report against an older release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub's private vulnerability reporting](https://github.com/SamCullin/gh-router/security/advisories/new) when possible. If that form is unavailable, contact [SamCullin through GitHub](https://github.com/SamCullin) and include `gh-router security report` in the subject.

Include the affected version, operating system, reproduction steps, expected behaviour, actual behaviour, and any relevant logs. Remove tokens and other sensitive values before sending logs.

Reports are reviewed privately. Fixes and public advisories are published when appropriate.
